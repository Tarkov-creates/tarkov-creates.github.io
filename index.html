🛠️ Troubleshooting Common Issues

Most problems are easy to solve. Try these quick checks before anything else.

The file will not open

Right-click the file and choose "Run as administrator", or check that the download finished completely. If Windows blocked it, open the file's properties and look for an "Unblock" checkbox at the bottom of the window.

Windows shows a security prompt

Click "More info" and then "Run anyway". This prompt appears for many downloaded programs and is not a sign that something is wrong.

My antivirus flags the file

Some security tools are cautious about any file downloaded from the internet. If you trust the source page, add an exception for the file in your antivirus settings, or temporarily pause the scan while you run it.

The menu does not appear in game

Make sure the game is running first, then open the menu. If it still does not show, close both the game and the menu program, and start them again in that order.

The game feels slow

Close other large programs, lower your in-game graphics settings, and make sure your computer is plugged in and not in a power-saving mode.
